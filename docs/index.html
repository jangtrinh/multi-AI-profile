01 · NHU CẦU & GIẢI PHÁP KIẾN TRÚC

Vì sao cách dùng osacompile bị lỗi trùng tên cửa sổ, và cách multi-AI-profile xử lý tận gốc.

Khi chạy nhiều tài khoản (Cá nhân, Công ty, Dự án phụ) trên Claude, Antigravity, Codex hay Grok, bạn cần phân biệt tức thì trong AltTab / Mission Control và tách biệt hoàn toàn cấu hình MCP Server lẫn CLI Home.

01 · VẤN ĐỀ VỚI OSACOMPILE

Trùng tên & trùng icon trong AltTab

Script open -n -a "Claude" --args --user-data-dir=... chỉ là trình mồi rồi thoát ngay. Cửa sổ thật vẫn chạy từ tiến trình gốc trong /Applications/ nên macOS WindowServer hiển thị cả 3 cửa sổ cùng tên và cùng icon (hoặc bị Assets.car đè icon).

02 · APFS COW + MACH-O WRAPPER

0 MB ổ cứng · Tên cửa sổ riêng biệt

Dùng cp -cR (APFS Copy-on-Write) nhân bản bundle trong <1 giây với 0 MB tốn thêm, patch Info.plist + toàn bộ Framework Helpers, xóa Assets.car override và biên dịch thực thi Mach-O execv() chính chủ.

03 · MULTI-LAYER AI ISOLATION

Cô lập cả UI, Daemon & CLI Home

Tách riêng cả tầng Electron UI lẫn tầng Daemon/CLI bên dưới: CLAUDE_CONFIG_DIR cho Claude, --gemini_dir cho Go language_server của Antigravity, CODEX_HOME cho OpenAI Codex, và GROK_HOME + SAND_DATA_ROOT cho xAI Grok.

Cài đặt một lần trong 10 giây.

Cài đặt đồng thời lệnh tổng ai-profile, 4 lệnh tắt (claude-profile, agy-profile, codex-profile, grok-profile) vào ~/.local/bin và tích hợp sẵn Agent Skill.

Terminal — macOS (zsh / bash)

cd multi-AI-profile
./install.sh
04 · CLI REFERENCE & COLOR PRESETS

Tạo thêm bất kỳ profile nào chỉ với 1 dòng lệnh.

Usage Examples 
# 1. Tạo các bản Work (nhãn xanh dương) cho cả 4 nền tảng AI
ai-profile create claude "Work" --color blue
ai-profile create antigravity "Work" --color blue
ai-profile create codex "Work" --color blue
ai-profile create grok "Work" --color blue

# 2. Tạo các bản Extra (nhãn tím)
ai-profile create claude "Extra" --color purple
ai-profile create antigravity "Extra" --color purple
ai-profile create codex "Extra" --color purple
ai-profile create grok "Extra" --color purple

# 3. Tạo cho Cursor, Windsurf, Cline hoặc bất kỳ ứng dụng .app nào trên máy
ai-profile create cursor "Work" --color emerald
ai-profile create custom "Work" --app "/Applications/Perplexity.app" --color cyan

# 4. Liệt kê hoặc gỡ bỏ profile
ai-profile list
ai-profile remove codex "Extra"

05 · FREQUENTLY ASKED QUESTIONS

Câu hỏi thường gặp.

Tại sao không dùng osacompile và open -n -a --args --user-data-dir?

Cách dùng osacompile chỉ tạo một script mồi mở lại tiến trình gốc trong /Applications/. Do macOS WindowServer, AltTab và Mission Control đọc tên cửa sổ và icon từ Info.plist của tiến trình đang chạy (kèm các Helper apps và Assets.car), tất cả các cửa sổ đều bị trùng tên và trùng icon.

Nhân bản nguyên một file .app nặng hàng trăm MB có làm đầy ổ cứng không?

Không. Công cụ sử dụng cờ cp -cR (APFS Copy-on-Write clonefile) trên macOS, giúp bản sao dùng chung các data blocks vật lý với ứng dụng gốc. Dung lượng ổ cứng tăng thêm là 0 MB và quá trình clone hoàn tất dưới 1 giây.

Làm sao OpenAI Codex, xAI Grok và Google Antigravity tách biệt được cả tiến trình ngầm và CLI?

ai-profile biên dịch một Mach-O binary wrapper cho từng nền tảng: với Antigravity sẽ bọc cả Antigravity UI (--user-data-dir) và Go language_server (--gemini_dir, --app_data_dir); với Codex/ChatGPT sẽ tiêm CODEX_HOME và CODEX_ELECTRON_USER_DATA_PATH; với Grok sẽ tiêm GROK_HOME, SAND_DATA_ROOT và SAND_USER_DATA_DIR.

Mỗi profile có dùng riêng được cấu hình MCP Server không?

Có 100%. Mỗi profile có một thư mục dữ liệu và file cấu hình MCP độc lập (claude_desktop_config.json cho Claude, mcp_config.json cho Antigravity, config.toml cho Codex và Grok), cho phép gắn MCP nội bộ công ty vào bản Work mà không ảnh hưởng đến bản Personal.
